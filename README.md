Abyss Protocol: Mathematical Information-Processing Systems

A dual-app interactive educational platform that explores the evolution of mathematics by treating historical and modern math traditions as distinct "information-processing systems."

Live Demo: abyss-protocol.com

📌 Features

This repository contains two interconnected, single-file web applications built with vanilla HTML, JS, and Tailwind CSS.

1. The Universal Number Rosetta Stone (index.html)

An interactive calculator that translates standard modern decimal integers (1 - 5000) into 8 distinct historical mathematical structures simultaneously:

Egyptian (Base-10 Additive / Hieroglyphics)

Babylonian (Base-60 Positional / Cuneiform)

Roman (Subtractive)

Greek (Ionic Alphabetic)

Chinese (Multiplicative-Additive)

Indian (Devanagari Positional)

Islamic (Eastern Arabic Positional)

The page also features a Systemic Math Traditions Dashboard that allows users to select and compare the core "architectural optimizations" of these ancient traditions side-by-side.

2. The Modern Math Sandbox (modern.html)

An interactive physics/math playground demonstrating how modern mathematics utilizes different structural representations to process specific types of data. Features real-time interactive sandboxes for:

Binary (Base-2): Interactive bit-switches proving decimal conversion.

Hexadecimal: Live RGB color-mixing engine demonstrating data density.

Complex Numbers: A kinetic 2D coordinate plane demonstrating phase and rotation.

Vectors: A draggable force-simulator calculating magnitude and direction.

🛠 Tech Stack

Designed to be ultra-lightweight, zero-dependency, and instantly deployable.

Structure: HTML5

Styling: Tailwind CSS (via CDN)

Icons: Lucide Icons (via CDN)

Logic: Vanilla ES6 JavaScript (No build steps required)

🚀 Deployment

This project is configured to run as a static site and is currently deployed via GitHub Pages.

To run locally, simply clone the repository and open index.html in any modern web browser. No server environment or npm install is required.
